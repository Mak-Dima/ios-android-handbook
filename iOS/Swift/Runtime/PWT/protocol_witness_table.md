In Swift, when you call a protocol method on a type whose exact concrete identity isn't known at compile time,              
Swift needs a way to locate the correct method implementation at runtime.               
It solves this using a Protocol Witness Table (PWT) 📋.            


A PWT is a table of function pointers generated by the Swift compiler for every unique (Type, Protocol) conformance (for example, Int conforming to Equatable).             
The term "witness" comes from type theory: the table witnesses (proves and provides) how that specific type fulfills all the requirements of the protocol.              
When code calls a protocol method dynamically, Swift looks up the corresponding function pointer inside the PWT and executes it ⚙️.

```swift
import Foundation

protocol Shape {
    fucn area() -> Double
}

class Recrangle: Shape {
    var width: Double
    var height: Double

    init(width: Double, height: Double) {
        self.width = width
        self.heght = height
    }

    func area() -> Double {
        Double(width * height)
    }
}

struct Square: Shape {
    var side: Double

    func area() -> Double {
        Double(side * side)
    }
}

var rectangle = Rectangle(width: 10, height: 20)
rectangle.area()

var square = Square(side: 10)
square.area()

// Starting Swift 5.6
// var anyShape: any Shape
// make it visually obvious to developers.
var anyShape: Shape
anyShape = Square(side: 30)
ahyShape.area()
```
